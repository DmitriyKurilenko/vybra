# Выбра

Попарное сравнение желаний с ELO-рейтингом и проверкой бюджета. React + Vite.
Финальный визуальный стиль — **«Контраст»** (светлая/тёмная тема, акцент `#FF4D2E`).

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
```

Без бэкенда приложение работает на **встроенном моке** (данные в localStorage) —
открывается и кликается сразу после `npm run dev`.

## Адаптивность

- **Десктоп** (≥1000px) — левый сайдбар + широкая контент-область (подиум и бюджет
  в две колонки, избранное сеткой карточек, сравнение — две крупные карточки в ряд).
- **Мобайл** — контент во весь экран + нижняя таб-панель, шторки снизу.

Брейкпоинт и режим переключаются хуком `useDesktop()` (`src/state/useMedia.js`).

## Подключение бэкенда

1. `cp .env.example .env`
2. Пропиши `VITE_API_URL=https://твой-api`
3. Перезапусти `npm run dev`.

Как только `VITE_API_URL` задан, весь UI автоматически ходит в реальный API
(`src/api/client.js`) вместо мока. Контракт эндпоинтов — в **BACKEND.md**.

## Структура

```
src/
  main.jsx              вход
  App.jsx               флоу: онбординг → подключение → приложение (табы)
  index.css             глобальные стили + анимации
  theme/tokens.js       палитра «Контраст», категории, форматтеры
  lib/elo.js            расчёт ELO и подбор пары
  api/
    index.js            выбирает mock или http по VITE_API_URL
    mock.js             офлайн-бэкенд (in-memory + localStorage)
    client.js           реальный HTTP-клиент
  state/
    useApp.js           состояние + действия поверх api
    useMedia.js         брейкпоинты + тема
  components/           Icon, ui (карточки/кнопки/графики), Shell (каркас)
  screens/             Onboarding, Connect, Compare, Top, Favorites, Profile, AddSheet
```

## Что заменить при интеграции

- **Картинки товаров** — сейчас тонированные плейсхолдеры по категориям
  (`CatBlock`). Подставь реальные фото из API.
- **ELO** — для продакшена считай на сервере (см. BACKEND.md), клиентский
  `eloUpdate` оставлен только для мока.
- **Парсинг ссылок** (`parsePreview` в `mock.js`) — заглушка по ключевым словам.
  В реальном API это эндпоинт `POST /api/preview`.
- **Профиль** — данные пользователя сейчас захардкожены («Аня К.»).
