# Versioning

This project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

- **MAJOR** — incompatible infrastructure or API changes
- **MINOR** — new features, integrations, or significant behavior changes
- **PATCH** — bug fixes, small corrections, security patches

Bump rules:
- Patch: backwards-compatible bug fix
- Minor: new functionality, backwards-compatible
- Major: breaking change that requires operator intervention
